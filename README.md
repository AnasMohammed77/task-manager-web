# Task Management System

A simple and responsive web-based Task Management System developed using HTML, CSS, and JavaScript. The application allows users to create, edit, delete, search, and manage daily tasks while storing data locally in the browser using LocalStorage.

---

## 📌 Overview

This project is designed to help users organize and manage their daily tasks efficiently through a clean and user-friendly interface.

The application enables users to add tasks with different priorities, update task details, mark tasks as completed, search for tasks instantly, and view task statistics. All data is stored locally in the browser without requiring a database or server.

---

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or pending
- Search tasks instantly
- Filter tasks by status
- Task priority management
- LocalStorage data persistence
- Task statistics dashboard
- Responsive user interface
- Smooth animations and transitions
